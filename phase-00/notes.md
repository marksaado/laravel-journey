# ملاحظات المرحلة 0: البداية العملية

## موقع الويب في جملتين
- **Client (العميل):** المتصفح. يرسل **request (طلباً)** إلى عنوان (URL).
- **Server (الخادم):** حاسوب يستقبل الطلب ويرسل **response (رداً)**: صفحة HTML أو بيانات.
- Laravel يعمل على الخادم: يستلم الطلب، ويقرر ماذا يرد.

## الأدوات
| الأداة | وظيفتها |

| VS Code | محرر الكود |
| Git | يحفظ تاريخ التغييرات في الكود |
| Node.js + npm | تشغيل JavaScript خارج المتصفح، وتثبيت حزم الواجهة |

## PATH وalias
- **PATH:** قائمة المجلدات التي تبحث فيها الطرفية عن البرنامج حين تكتب اسمه.
- Herd على Windows يضع `php.bat` و`composer.bat`. PowerShell يشغّلهما باسم `php`، أما Bash فلا.
- الحل: في `~/.bashrc`:
  ```bash
  alias php="php.bat"
  alias composer="composer.bat"
  ```
- `alias الاسم="الأمر"`: الكلمة التي تكتبها = ما يُنفَّذ فعلاً. لا مسافات حول `=`.
- `which` يبحث في PATH فقط ولا يرى الـ aliases. للتحقق: `type php`.

## سطر الأوامر: التنقل
| الأمر | السؤال الذي يجيب عنه |
|---|---|
| `pwd` | أين أنا؟ |
| `ls` | ماذا يوجد هنا؟ |
| `cd اسم` | ادخل إلى مجلد داخل مكاني |
| `cd ..` | اصعد خطوة |
| `cd ~` | المجلد الرئيسي |
- `/` وحدها هي جذر النظام (أعلى نقطة). `E:` تُكتب `/e/`.
- الطرفية تعرض مكانك الحالي في السطر قبل `$`.

## سطر الأوامر: الإنشاء
- `mkdir a b c` ← ثلاثة مجلدات. المسافة تفصل بين الأسماء.
- `mkdir -p site/css` ← يُنشئ `site` أيضاً إن لم يكن موجوداً.
- `touch a.html b.css` ← ملفات فارغة. touch لا يُنشئ مجلدات: المجلد يجب أن يكون موجوداً.

## سطر الأوامر: النسخ والنقل والحذف
- `cp مصدر هدف` ← نسخة، والأصل يبقى.
- `mv مصدر هدف` ← الأصل يختفي. الهدف اسم جديد = إعادة تسمية. الهدف مجلد موجود = نقل.
- `rm ملف` / `rm -r مجلد` ← حذف نهائي بلا سلة محذوفات.

## سطر الأوامر: الكتابة والقراءة
- `echo "نص"` ← يطبع على الشاشة فقط.
- `echo "نص" > ملف` ← يمسح الملف ويكتب. `>>` ← يضيف في الآخر.
- `cat ملف` ← يعرض المحتوى.
- النسخة (`cp`) لقطة لحظة النسخ: لا تتغير إذا تغيّر الأصل بعدها.

## Git: البداية
- **commit** = لقطة محفوظة من المشروع. **repo** = مجلد يراقبه Git (فيه `.git/` المخفي).
- مرة واحدة على الجهاز: `git config --global user.name/user.email`، و`init.defaultBranch main`.
- `git init` ← يجعل المجلد repo. `ls -a` يُظهر المخفي.
- `git status` ← أهم أمر: نفّذه قبل كل خطوة وبعدها.
- **Untracked** = Git يرى الملف لكنه لا يراقبه، لأننا لم نضفه بعد بـ `git add`.
