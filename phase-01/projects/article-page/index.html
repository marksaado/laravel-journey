What is HTML?

HTML stands for HyperText Markup Language. It is the standard markup language used to structure content on web pages. It tells the browser how different parts of a webpage should be organized.

Elements

An HTML element usually consists of an opening tag, content, and a closing tag. The opening tag defines where the element begins, the content is what appears inside it, and the closing tag marks where the element ends. Here are three examples:

  • <main>Main content</main>: Contains the main content of the page.
  • <nav>Navigation links</nav>: Contains navigation links.
  • <p>Some text</p>: Defines a paragraph of text.

Attributes

HTML attributes provide additional information about an element. They are written inside the opening tag and usually consist of a name and a value. For example, the href attribute specifies the destination of a link: <a href="https://example.com">.

Semantic HTML

Semantic HTML means using elements that clearly describe their purpose and the type of content they contain. For example, elements like header, nav, main, article, and footer help browsers, search engines, and screen readers understand the structure of a webpage. This improves accessibility, readability, and SEO.
